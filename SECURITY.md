# Security Policy

## Supported Versions

Security and bug fixes are generally provided for the latest released version.
Unless explicitly stated otherwise, older releases are not maintained separately
for security issues.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, pull
requests, discussions, or other public channels. This project has GitHub Private
Vulnerability Reporting enabled. This is the preferred way to report security
vulnerabilities.

For general security questions, hardening recommendations, or non-sensitive
security discussions, please use the project's GitHub Issues. Do not include
sensitive vulnerability or any other confidential information in public issues.
For suspected vulnerabilities, please use the private vulnerability reporting
process described above.
